# PDF 图表提取方案与本地复核

## 目标与当前状态

目标是在设备端从用户提供的 PDF 导出每一幅真实的论文图、每一张真实的表：主体完整、原分辨率尽可能高，并包含整段图题或表题、面板标签及所属的 Note、Source、统计说明等。导出框不应混入相邻正文或另一项图表。

当前只完成**方案验证**，尚未把自动提取功能接入 PaperLens。`tools/figure-extract.html` 是可在浏览器运行的半自动提取实验页：自动列出文字标题候选，人工逐页确认并调框，再从原 PDF 高倍率导出。`output/figure-validation/manifest.json` 记录了已由原页目视复核的截图；对应 PNG 位于同目录。验证资料与 `downloads/` 都被 `.gitignore` 排除，不属于产品运行代码。验证状态与已知失败实例见 [验证记录](../output/figure-validation/README.md)。

## 产品中的处理流程

1. **读取和去重。** 用户选择 PDF 后，使用现有 PDF.js 在浏览器或 Android WebView 内打开；按文件哈希识别同字节副本。所有坐标统一为 `page.getViewport({scale: 1})` 的左上角坐标，不混用 PDF 底部坐标。文件和导出图仍留在本地。
2. **建立可核对的编号清单。** 从 `getTextContent()` 的文字项聚合行和段，识别 `Figure`、`Fig.`、`Table`、`Extended Data Fig.`、`S1`、`2.1`、中文「图/表」等编号。保留完整编号、页码、文本和文字框；区分真实标题、正文引用、图目录/表目录、占位符、参考文献与译文重复页。正文的引用编号可用来反查漏掉的标题，但不能凭引用生成图片。
3. **产生候选主体区域。** 对图，综合 PDF.js 页面绘制操作、图片对象和低倍率页面渲染所得的图形区域；图可能全由矢量路径组成，不能只看图片对象。对表，综合标题、单元格文字的列对齐、横竖线与表格边界。以页的分栏和相邻标题为边界，判断主体位于标题上方还是下方。多面板图按总图题组成一项；同页紧邻的两幅图按各自图题和实际对象边界拆分。
4. **补全附属文字。** 图题可能跨多个文字块，也可能与下一节标题同块；按文字行、缩进、行距和上下文确定终点。表格后的 `Note:`、`Source:`、星号或匕首脚注均纳入所属表。不能仅凭标题首行框裁切。
5. **强制进入复核队列。** 标题重复、编号缺口、没有匹配标题的大面积图像或表格线、近零可提取文字页、扫描页、图形与正文重叠、跨页表、图片对象贴页边、超长标题以及中英重复页，都必须显示原页供人工确认。逐页展示“已识别项目数”和“尚待检查页面”，用户确认后才标记该 PDF 完成。DeepSeek 视觉识别可作为可选的语义交叉检查；实测其预测框可能漏掉多行图题，故不直接采用模型坐标。
6. **导出与复核。** 用户在原页预览里拖动框并确认，保存来源、页码、编号和矩形。使用 PDF.js 的 `page.render` 按裁切框直接重渲染，建议默认 4 倍（约 288 dpi），而非放大低清整页截图。Canvas 大小为 `(x1-x0)×4`、`(y1-y0)×4`；渲染变换平移 `[-x0×4, -y0×4]`。若尺寸或设备内存超限，则降低倍率或分块渲染并明确显示实际像素尺寸。导出 PNG 后检查四边内容余量，用边缘像素扫描提示异常；像素扫描只提示风险，最终仍需与原页核对。
7. **完成条件。** 每个真实编号恰有一项导出结果；所有未匹配引用、异常页与低文字页都有处理结论；用户逐项确认主体、图题、面板文字、脚注、最外表线和相邻区域。不能把“正则命中数连续”或“成功写出 PNG”当作无遗漏证明。

跨页表以同一编号保存有序的 `part_1`、`part_2` 等页面片段，末页脚注必须随所属表保存；若需要单张图片，可在逐段确认后于浏览器 Canvas 中按顺序拼接并标明页间接缝。当前实验页一次只导出单页框，跨页项目仍需人工记录，不能标记为完成。

## 现有验证结果告诉我们什么

- 当前 50 份 PDF、1178 页中，3 对文件内容完全重复；文字扫描的 869 条候选不等于真实图表数。
- 候选框实验能减少定位工作，但曾漏掉顶部图片、纵轴、最右刻度、表格横线和跨块图题，也曾把正文或另一幅图带入。验证记录保留了具体论文和页码。
- PDF.js 已对矢量图、长脚注表、双栏图题与横向表进行过 4 张导出对照；页面裁切渲染路径可用。手机浏览器的大图内存与速度尚需实测。
- 浏览器实验页的标题扫描逻辑已用 PDF.js 对现有 137 张截图所在原页回归：137 项均找到同页同编号的候选。旧清单有 7 个文件名标签使用附注后缀或把章节小数点写为下划线；按原始图表编号归一化后匹配。此结果只证明已知样本的标题召回，不能证明其他页面无漏检。实验页的 4 倍裁切渲染也已用一张真实 PDF 图与原页对照。
- 进一步用相同扫描逻辑遍历 `downloads/` 的 50 份 PDF、1178 页，得到 877 条待审标题候选，文件均能打开。这个数包含正文引用、图表目录和重复/翻译页面，不能当作真实图表总数。全库对照还发现正文与图题处于近似同一文字行、以及独立的 `Table 2.` 短行会漏报，实验页已修正规则并重新完成全库扫描；修正后上述 137 项仍全部命中。
- `manifest.json` 是已复核结果；`figure_geometry_proposals.json`、`table_geometry_proposals.json` 仅是待审候选，不能当作完成的导出清单。

## 人工验收方法

按**每份不同内容的 PDF**验收，而不是拿全库候选总数当目标数。同字节副本可以复用一份结果，但清单中仍要记录哪些文件复用了它。

1. **先定真实数量。** 从第一页到最后一页逐页看原文，独立记下每个真实 Figure、Table、扩展数据图和补充表的完整编号及所在页；再与标题扫描候选、图目录/表目录、正文引用核对。候选外的图形页、扫描页、零候选 PDF 和附录也必须看。对每条被排除的候选记录理由（引用、目录、占位符、重复译文等）。
2. **逐项对照 PNG。** 每个真实图表必须能找到对应 PNG 和清单记录；在原页上确认全部面板、坐标轴/刻度、表格最外线、整段标题、`Note`/`Source`/符号脚注均在框内，且没有相邻正文或其他图表。四边像素余量小于 6 px 或大于 50 px 的提示要重点检查，但正常余量也不能替代原页对照。
3. **核对文件与清单。** 清单记录源 PDF 的 SHA-256，以及页码、完整编号、裁切坐标、像素尺寸、PNG 文件名；这些字段须与实际文件一一对应，重新打开 PNG 确认不是空白或损坏。浏览器本地进度只保存记录，不保存已下载的 PNG，因此须同时保管 PNG 与 JSON。导入复核清单时，实验页会核对原文件的哈希。
4. **处理例外后再通过。** 跨页表应按页保存有序片段并核对末页脚注；无法在实验页准确处理的项目记为待处理。只有真实编号集合与导出结果集合一致、所有页和异常候选均有结论、全部 PNG 经原页核对后，才可判为该 PDF 通过。实验页 JSON 中的 `complete` 只是操作进度标记，不是这个验收结论。

## 在当前工作区运行实验页

在项目根目录执行：

```bash
npm install
npm run dev
```

**对新 PDF 试跑提取：**打开终端给出的本地地址，在末尾加 `/tools/figure-extract.html`，例如 `http://localhost:5173/tools/figure-extract.html`。选择一份 PDF，点击“扫描标题”；列表中的 `?` 是待审候选。点选候选后，在原页拖动重画橙色框，或直接输入 `x0/y0/x1/y1`；填写编号，点击“生成高清截图”，检查右侧预览及四边内容余量提示。贴边可能截断，留白过多可能框太大；像素提示无法判断是否漏了图题或脚注，仍须与原页目视对照。超出原页的手填坐标会被拒绝。确认后点“确认并下载 PNG”。“下载预览”只保存试裁图；“确认并下载 PNG”会生成唯一文件名并将它记入清单，记录四边像素余量。误识别的正文引用可点“排除候选”；没有候选的真实图表用“新增当前页项目”。每页看完后勾选“本页已核对”。可随时下载草稿 JSON；重新选择同一 PDF 会从当前浏览器的本地存储恢复进度，也可在选择原 PDF 后导入已下载的 JSON。全部页面和候选检查后下载完整复核清单，再切换下一份 PDF。实验页一次处理一份 PDF；请保存每份论文的 PNG 和 JSON。JSON 的 `complete` 只表示这些人工复核步骤已被标记完成，不自动证明内容正确。

**检查现有验证样本：**打开 `/tools/figure-review.html`。选择论文和图表，左边看原 PDF 页与橙色裁切框，右边看已导出的 4 倍 PNG；点击右侧图片可单独放大。使用“上一项/下一项”逐张核查。页面直接读取本地 `downloads/` 与 `output/figure-validation/manifest.json`，不调用翻译 API，也不写回 PDF。

当前工作区的验证目录是忽略提交的本地资料；如果移到新机器，需连同 `downloads/` 和 `output/figure-validation/` 一并复制，现有样本复核页才有原件和截图可读。新 PDF 提取实验页只依赖用户选择的文件。标题扫描可能把正文引用误列为候选，也可能漏掉没有可提取标题的图表；必须浏览所有页并保存核对记录。实验页尚未实现自动图形/表格精确定位和批量打包，正式产品应按上面的完整流程实现。
